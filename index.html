Tago — RFID Attendance System

An RFID-based attendance platform for schools, built for an NCEA Level 3 assessment and taken well past the brief. Rebuilt the entire backend from a Python/Flask starter into a Node/Express API on Supabase, then layered on security and reliability work nobody asked for: an origin allowlist, hardened response headers, per-route rate limiting, and Row-Level Security enforced independently of the API as a second, database-level line of defence. Extended the schema with ten migrations covering student onboarding, an appeals workflow with a full audit trail, an emergency roll-call system with live cross-device sync, and offline scan buffering for when classroom Wi-Fi drops out. The React dashboard runs on ten live Supabase Realtime subscriptions, is role-gated at the route level, and ships with a Playwright regression suite enforcing its own design rules and accessibility fallbacks — alongside a public privacy policy mapped against all 13 principles of the NZ Privacy Act 2020.
